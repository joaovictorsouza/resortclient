# ADR 0001: Adoção do Bevy 0.19 e Avian 0.7

## Status
Aceita

## Contexto
O Bevy 0.20 foi lançado recentemente (08/10/2026), porém a biblioteca de física Avian3D encontra-se na versão 0.7, que tem compatibilidade estrita com `bevy ^0.19.0`.

## Decisão
Adotar **Bevy 0.19** combinado com **Avian 0.7** para garantir estabilidade imediata e compatibilidade total de compilação da engine de física. A migração para Bevy 0.20 ocorrerá assim que o Avian lançar a versão correspondente.

## Consequências
- Ecossistema de física 3D 100% funcional sem forks experimentais.
- Acesso às novas APIs do Bevy (como `Message` para comunicação buffered desacoplada).
